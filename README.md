# NammaSathi – Your Kannada Communication Companion

**Breaking language barriers, one conversation at a time.**

NammaSathi is an AI-powered multilingual web application designed to make Kannada more accessible in everyday life. It helps users communicate between English, Hindi, and Kannada through AI-assisted translation, contextual language support, interactive practice, and a practical phrasebook.

Developed for the **Kannada in Everyday Life** problem statement.

---

## 🌟 Key Features

### 1. AI-Powered Translation

* Translate between English, Hindi, and Kannada.
* AI-assisted language translation using Google Gemini.
* Context-aware translation for practical communication.

### 2. Context-Based Communication

Supports different everyday scenarios:

* Healthcare
* Shopping
* Transportation
* Education
* Workplace
* General communication

### 3. Kannada Practice

* Interactive language-learning experience.
* Helps users improve their Kannada vocabulary.
* Encourages regular language practice.

### 4. Everyday Phrasebook

* Access commonly used expressions.
* Find useful phrases for daily situations.
* Make everyday communication easier.

### 5. User Settings

* Manage application preferences.
* Simple and accessible interface.

## 🎯 Problem We Address

Language barriers can make everyday communication difficult, especially when people need to interact in unfamiliar environments.

NammaSathi addresses this challenge by bringing together AI-assisted translation, practical language learning, and commonly used expressions in one accessible platform.

Our goal is to encourage Kannada usage and make communication more inclusive.
